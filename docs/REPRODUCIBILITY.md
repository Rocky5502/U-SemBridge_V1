# Reproducibility Protocol

Every reported run must record: git commit; dataset version/hash; model repository and exact revision; tokenizer revision; prompt hash; decoding parameters; seed; solver name/version/timeouts; hardware/software environment; raw candidate CIR outputs; compiled formula; solver output; uncertainty components; calibrated risk; final policy action; and per-example metrics.

All final tables and figures must be generated from machine-readable result files. Manual entry of final numeric values is prohibited except labeled sanity-check annotations.
