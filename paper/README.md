# Manuscript synchronization

The full IJUFKS manuscript is maintained in the project’s Overleaf/paper package while experiments are still changing. This code repository intentionally avoids keeping a second stale copy of a 15+ page manuscript before results are frozen.

Before submission, sync the final `main.tex`, bibliography, figures, generated result tables, and current official World Scientific IJUFKS template into this folder or an archival release tag.

Non-negotiable rule: manuscript result values must be generated from machine-readable outputs, never manually invented or estimated.
