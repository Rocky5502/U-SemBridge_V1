# Third-party datasets and code

U-SemBridge does not vendor third-party datasets or baseline repositories.

| Resource | Upstream | Intended use | Redistribution policy here |
|---|---|---|---|
| FOLIO | https://github.com/Yale-LILY/FOLIO | primary NL-to-FOL benchmark | fetched locally; not committed |
| Logic-LM | https://github.com/teacherpeterpan/Logic-LLM | baseline + reference preprocessed data | fetched locally; not committed |
| LINC | https://github.com/benlipkin/linc | baseline reproduction | fetched locally; not committed |
| ProofWriter | upstream/research releases referenced by baseline repositories | OWA True/False/Unknown stress test | fetched/linked locally; not committed |

Before publishing derived artifacts, check each upstream license and citation requirement. Data/baseline fetch scripts record the exact upstream commit used.
